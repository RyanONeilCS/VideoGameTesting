# Builds

Ready-to-play Windows builds of the Stalker prototype. No Unity needed.

## How to play
1. Download the build's whole folder (use the newest: `BuildV2`). The game needs every file in it, not just the `.exe`.
2. Run `StalkerPrototype.exe`. If Windows warns "unknown app", click **More info → Run anyway**. If it asks about the firewall, click **Allow**.
3. In the menu:
   - **Solo:** play alone.
   - **Host on this network / Join address:** play together on the same network. The joiner types the host's IP address.
   - **Host online / Join code:** play over the internet. The host gets a JOIN CODE (top right; Esc → Copy code) and sends it to the others. Includes proximity voice chat (V = mute). *(BuildV2 and newer only.)*

Everyone in a match must use the **same build**.

## Versions
| Build | Contents |
|---|---|
| BuildV1 | Multiplayer part 1 (Solo, local-network Host/Join). Online join codes and voice chat need a newer build. |
| BuildV2 | Adds **online play with join codes** and **proximity voice chat** (project linked to Unity Cloud). |

# Builds

Ready-to-play Windows builds of the Stalker prototype. No Unity needed.

## How to play
1. Download the build's whole folder (for example `BuildV1`). The game needs every file in it, not just the `.exe`.
2. Run `StalkerPrototype.exe`. If Windows warns "unknown app", click **More info → Run anyway**. If it asks about the firewall, click **Allow**.
3. In the menu:
   - **Solo:** play alone.
   - **Host on this network / Join address:** play together on the same network. The joiner types the host's IP address.
   - **Host online / Join code:** play over the internet with a join code. *(Not in BuildV1: that build was made before the project was linked to Unity Cloud.)*

Everyone in a match must use the **same build**.

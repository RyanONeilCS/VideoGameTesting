# Builds

Ready-to-play Windows builds of the Stalker prototype. No Unity needed.

## How to play
1. **Easiest:** click `BuildV4.zip` in this folder, then the **Download** button (↓, top right of the file view). Unzip it (right-click → Extract All).
   The game needs every file in the folder, not just the `.exe`.
2. Run `StalkerPrototype.exe`. If Windows warns "unknown app", click **More info → Run anyway**. If it asks about the firewall, click **Allow**.
3. In the menu:
   - **Solo:** play alone.
   - **Host on this network / Join address:** play together on the same network. The joiner types the host's IP address.
   - **Host online / Join code:** play over the internet. The host gets a JOIN CODE (top right; Esc → Copy code) and sends it to the others. Includes proximity voice chat (V = mute). *(BuildV4 and newer.)*

Everyone in a match must use the **same build**.
